## 注意事項
- ファイル名は **半角英数字＋ハイフン** で揃えています。日本語/中文ファイル名は避けてください（モバイルブラウザで一部不具合あり）。
- 写真は **JPG**、ロゴ/バッジ/手偶切り抜きは **PNG（透過）** を推奨。
- スマホ最適化（390px幅基準）のため、書き出しは横幅 800px 程度で十分です。
